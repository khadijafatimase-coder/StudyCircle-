# StudyCircle – Learn Together, Grow Together

## Project Description
StudyCircle is a student learning platform prototype designed to help students connect with study groups and share learning resources. It provides a simple and user-friendly interface for accessing study-related features.

## Live Demo
**Website:** https://khadijafatimasecoder.pythonanywhere.com/

## Technologies Used
- HTML – Website structure
- CSS – Styling and layout
- JavaScript – Basic interactivity
- Python – Backend programming
- Flask – Web application framework
- SQLite – Database management

## Project Structure
- `app.py` — Main Flask application
- `requirements.txt` — Required Python packages
- `templates/` — HTML pages
- `static/` — CSS and JavaScript files
- `studycircle.db` — Database file generated by the application, if created

## Main Features
- Home page
- Login and registration pages
- Dashboard
- Study groups
- Learning resources
- Website navigation and user interaction

## How to Run the Project Locally

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the `studycircle-app` folder in Visual Studio Code.
4. Open the terminal in the project folder.
5. Install the required packages:

   ```bash
   python -m pip install -r requirements.txt
   ```

6. Run the application:

   ```bash
   python app.py
   ```

7. Open the following address in your browser:

   `http://127.0.0.1:5000/`
