Module 1 – Frontend Structure

Developed the basic frontend structure of the StudyCircle web application using HTML and CSS. Created the Home, Login, Register, and Dashboard pages with navigation, responsive layout, forms, cards, buttons, and study-resource

Module 2 – Frontend Interaction

Implemented JavaScript functionality for form validation, navigation, button interactions, search, category filtering, login/register feedback, joining study groups, and logout functionality. The frontend prototype provides basic interactive features required for the StudyCircle platform.
