# StudyCircle – Module 3

## Project Name
StudyCircle – Study Group Platform

## Module
Module 3: Backend Development

## Technologies Used
- **HTML** – Webpage structure
- **CSS** – Website styling
- **JavaScript** – Basic interactions
- **Python** – Backend programming
- **Flask** – Web framework
- **VS Code** – Code editor
- **Web Browser** – Testing the website

## Tools & Libraries
- Flask
- Python Terminal
- HTML Forms
- Flask Sessions and Routes

## Files Used
- `app.py` – Backend application
- `requirements.txt` – Python dependencies
- `templates/index.html` – Home page
- `templates/login.html` – Login page
- `templates/register.html` – Registration page
- `templates/dashboard.html` – Dashboard page
- `static/style.css` – Website styling
- `static/script.js` – JavaScript interactions

## Features
- User registration and login
- Logout functionality
- Session management
- Study resource display
- Search and category filtering

## How to Run
1. Install Flask:
   `python -m pip install Flask`
2. Run the application:
   `python app.py`
3. Open `http://127.0.0.1:5000/` in your browser.

## Database
MySQL integration is planned for Module 4. Currently, the backend uses temporary in-memory data.
