# StudyCircle — Learn Together, Grow Together

## Project Overview
StudyCircle is a full-stack web development prototype designed to help students learn collaboratively. It provides a simple website where students can register, log in, explore study groups, and access learning resources.

## Features
- Home page
- User registration and login
- User dashboard
- Study groups
- Learning resources
- Search and filtering
- Database integration

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Template Engine:** Jinja2
- **Code Editor:** Visual Studio Code

## Project Structure
- `app.py` — Flask application
- `requirements.txt` — Required Python packages
- `templates/` — HTML pages
- `static/` — CSS and JavaScript files
- `studycircle.db` — Local database file generated by the application

## How to Run the Project
1. Install Python.
2. Open the project folder in Visual Studio Code.
3. Install the required packages:

   `python -m pip install -r requirements.txt`

4. Run the application:

   `python app.py`

5. Open `http://127.0.0.1:5000/` in your browser.
